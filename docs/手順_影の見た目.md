## 第1段：動きを整える

**作る物：`js/shadowmotion.js` に `createMotion(g, cfg)` を足す。** 影1本を受け取り、整えた姿勢を返す。描き方とは切り離す。

```js
const motion = createMotion(ghost, B.shadow.motion);
const pose = motion.at(tMs);        // poseAt と同じ形。ただし整えた後。必ず13点が入る（見えない点も埋める）
const meta = motion.metaAt(tMs);    // { facing: { shoulders, hips, twist, side }, seen: { 点の番号: 0〜1 }, planted: { 27: bool, 28: bool } }
```

作り方は「先に全部を計算して持っておく」形にする（再生のたびに計算しない）。影は長くても数十秒なので、作った時に1回、全コマを整えて配列に入れる。

### 手順（この順に掛ける）

| 順 | 手当て | 式 |
|---|---|---|
| 1 | 見えない点を埋める | 点ごとに、見えなかったコマ（x が −1）を探す。前後に見えたコマがあれば、その間を直線でつなぐ。片側しか無ければ、その値で止める。全コマで見えなかった点は、体の作りから置く（肘＝肩と手首の中点、膝＝腰と足首の中点、など）。埋めたコマは `seen` を 0 にし、見えたコマから `holdMs`（200ms）かけて 1 に戻す |
| 2 | 震えを取る（One Euro フィルタ） | 点ごと、x・y・z ごとに掛ける。`fc = minCutoff + beta × |速さ|`、`a = 1 / (1 + (fps / (2π × fc)))`、`値 = 前の値 + a × (今の値 − 前の値)`。速さも同じ形（cutoff 1.0）でならす。**前から後ろへ1回、後ろから前へ1回掛けて、平均する**（記録を後から見るので、遅れを打ち消せる） |
| 3 | 骨の長さをそろえる | 上腕・前腕・腿・脛の4種類（左右で8本）。長さは「3Dの長さ」＝ `√(dx² + (dy × 縦横比の逆数)² + dz²)`。奥行きが無い影は2Dの長さ。影全体での中央値を、その骨の長さとする。各コマで、付け根から先への向きはそのまま、長さだけ中央値に合わせて、先の点を置き直す。順番は 肩→肘→手首、腰→膝→足首 |
| 4 | 足を地面に付ける | 足首の点の速さが `footLock.speed`（絵の高さの 0.15 倍／秒）より遅い間は「着いている」とし、その間の位置を、着いた瞬間の位置に固定する。離れる時と着く時は 80ms でなめらかに切り替える。固定で足首が動いたぶん、膝は腰と足首の間で置き直す（脛と腿の長さを保つ。2本の骨の関節の計算） |
| 5 | コマの間を補う | `at(t)` は、前後4コマを使う Catmull-Rom の曲線で返す（今の `poseAt` は直線）。端のコマは、端の値をくり返す |
| 6 | 向き | 5の後の姿勢から `facingOf` を出す。向きの値も、順2と同じフィルタでならす（背中の ±180° をまたぐ時は、角度を足し算でつないでからならす） |

### 最初の値（`balance.json` の `shadow.motion`）

```json
"motion": {
  "_note": "（意味は balance.json の _note）",
  "smooth": { "minCutoff": 1.2, "beta": 8, "dCutoff": 4 },
  "holdMs": 200,
  "boneLock": "clamp",
  "footLock": { "speed": 0.15, "blendMs": 80, "drift": 0.02 },
  "interp": "curve"
}
```

**2026-11-16 に作って変えた所**（理由と数字は、設計資料の「第1段で分かったこと」）：`beta` 0.6→8 と `dCutoff` の追加（元の値では速い振りが鈍った）。`boneLock` は `false`／`"clamp"`（画面の上で伸びた時だけ縮める。初めの値）／`"full"`（上の表の順3のとおり。`true` も同じ）。骨の長さは左右別々の8本ぶん。`footLock.drift` の追加。順4の膝の置き直し（2本の骨の関節の計算）は `"full"` の時だけで、ほかは足首が動いたぶんの半分だけ膝を動かす。

### 試験場に足す物

- 描き方の選択肢とは別に、「動き：そのまま／整える」の切り替えを左右それぞれに足す。左を「そのまま」、右を「整える」にして、同じ描き方で比べられるようにする。
- 手当てを1つずつ切れるチェック（震え取り・骨の長さ・足・補い）。どれが効いているかを見るため。

### できたと言える条件

| 見る影 | 見る所 |
|---|---|
| ヒデキの「ゆっくり」 | 構えと残心で止まっている間、手先と頭が震えない |
| ヒデキの「速い連撃」 | 振りの速さが鈍らない（整える前と、手先の一番速い所の位置が、絵の高さの3%以上ずれない）。手先が飛ばない |
| ヒデキの「ひねり」「回転切り」 | 腕の長さが変わらない。横と背中で、点が飛ばない |
| 計算で作った影4本 | 整える前と後で、形がほとんど変わらない（元が正しいので、壊していないことの確認） |
| 全部 | ×0.25 で、コマとコマの間がなめらか。足が滑らない |

**やらないこと：** 型への寄せ（ヒデキの決定「まずは無し」）。判定に使う骨格の加工。

## 第2段：人形の骨組み

**作る物：`js/shadowpuppet.js` に `createPuppet(rig, opts)`。** 仮の部品（プログラムで描く黒い形）で、関節・重ね順・向き・ひねりを全部通す。**絵はまだ使わない。**

```js
const puppet = createPuppet(rig, { aura: [120,175,255], quality: "mid" });
puppet.draw(ctx, pose, box, { aspect, t, meta, ghost });   // meta は motion.metaAt(t)。無ければ pose から出す
```

試験場の `RENDERERS` に `{ id: "puppet", make: (g) => createPuppet(RIG, {...}) }` を足す。

### 描く順（これを守れば崩れない）

1. 姿勢の13点を、画面の点に直す（`ox + (1 - x) × bw`、`oy + y × bh`。今の描き方と同じ）。
2. 体の物差し `U` を決める：腰の中点から肩の中点までの長さ ÷ 1.5（正面で、ほぼ肩幅になる）。**肩幅から決めない**（横を向くと肩幅が0になるため）。
3. 向き `side`（正面・横・背中）と、肩の向き・腰の向きを `meta.facing` から取る。奥行きが無い影は、いつも正面として扱う。
4. 腕2本を「奥」と「手前」に分ける：手首と肘の z の合計が小さい（カメラに近い）ほうが手前。奥行きが無い影は、右腕（本人の右）を手前とする。脚も同じやり方で分ける。
5. 重ねる順に描く（下の表）。
6. 影の形ができたら、今の描き方と同じやり方で、にじみ・縁・残光を付ける（第5段で作り直すので、ここでは今のままでよい）。

| 順 | 正面 | 横 | 背中 |
|---|---|---|---|
| 1 | 奥の腕 | 奥の腕 | 手前側に来る腕は無い（両腕とも胴の向こう）→ 両腕 |
| 2 | 奥の脚（袴） | 奥の脚 | 両脚 |
| 3 | 胴 | 胴 | 胴 |
| 4 | 手前の脚 | 手前の脚 | 髷・後ろ髪 |
| 5 | 頭、髷 | 頭、髷 | 頭 |
| 6 | 鬼面・目 | 鬼面（横用。無ければ描かない） | 描かない |
| 7 | 手前の腕 | 手前の腕 | － |
| 8 | 刀 | 刀 | 刀（手が見えた時だけ） |

背中の時：腕が胴に隠れる。手首が胴の四角形の外に出ている部分だけが見える。これは描く順（腕を先、胴を後）で自然にそうなる。

### 胴（ひねりの要）

- 肩の線：肩の中点を中心に、左右へ `半幅`。腰の線も同じ。
- `半幅 = max( 画面上の半幅 × 1.25 , 厚み × |sin(向き)| + 厚み × 0.55 )`。厚みは、肩で `U × 0.34`、腰で `U × 0.30`。**横を向いても線1本に潰れない。**
- 肩の線の2点と腰の線の2点を結んだ四角形を塗る。肩の線の上に、丸い肩（楕円）を重ねる。
- 肩の向きと腰の向きは別々に使うので、ひねった時は四角形がねじれた台形になる。これがひねりの形。

### 腕・脚（先細りの部品）

- 1本の骨は、付け根の幅と先の幅を持つ台形＋両端の丸。幅は `U` に対する割合（上腕 0.17→0.14、前腕 0.14→0.11、腿 0.36→0.40、脛 0.40→0.46。袴なので脚は先が広い）。
- カメラ側へ向いて、画面上の長さが元の長さの半分より短くなった骨は、幅を `1 + (0.5 − 長さの割合) × 0.6` 倍に太らせる（手前へ突き出た腕が太く見える）。
- 関節には、太いほうの幅の丸を置く（つなぎ目を隠す）。

### 頭

- 中心は鼻の点から、上へ `U × 0.05`。半径は横 `U × 0.30`、縦 `U × 0.34`。
- 鼻が見えない時（背中）：肩の中点から、首の向き（腰の中点→肩の中点）へ `U × 0.62` の所。
- 髷：頭の中心から、上へ `U × 0.37`、後ろへ `−sin(肩の向き) × U × 0.34`。横を向くと後頭部へ回る。

### 刀

- 刀を見つけるAIの結果が影に入っていれば、それで描く（項目名は `sword: [[柄頭x, 柄頭y, 切っ先x, 切っ先y], …]`、コマごと。入るのは別の作業）。
- 入っていない時：今と同じ「前腕の延長」（両肘の中点 → 両手首の中点の向き）で描く。**骨格だけで刀の向きを当てる決め方は、見つかっていない。** ヒデキの写真26枚で、刀の印とのずれ（真ん中の値）を比べた結果：前腕の延長 64°、右手首→左手首 79°、左手首→右手首 136°、両手首の線に前腕の向きで表裏を付ける 86°、前腕と両手首の線の中間 65°。両手首の線は「表裏が分かれば」34°だが、表裏を骨格から決める方法が無い。枚数が少ないので、決め方を替える時は、もっと多い写真で比べ直すこと（比べ方は設計資料の9章）。長さは `U × 2.6`。
- それでも大きくずれるので、刃の本体は細く、残光は太くぼかす。

### 部品の定義（`data/shadow_rig.json`）

第2段では、仮の形の定義だけを書く。第3段で絵を足す時に、同じファイルに項目を足す。

```json

  "kits": {
    "samurai": {
      "front": {
        "upperArm": { "w": [0.17, 0.14], "img": null, "pivot": [0.5, 0.06], "tip": [0.5, 0.94] },
        "foreArm":  { "w": [0.14, 0.11], "img": null, "pivot": [0.5, 0.06], "tip": [0.5, 0.94] },
        "thigh":    { "w": [0.36, 0.40], "img": null, "pivot": [0.5, 0.05], "tip": [0.5, 0.95] },
        "shin":     { "w": [0.40, 0.46], "img": null, "pivot": [0.5, 0.05], "tip": [0.5, 0.95] },
        "torso":    { "shoulder": 0.34, "hip": 0.30, "img": null },

    }

```

`side` が空の間は `front` を使う。

### できたと言える条件

| 見る影 | 見る所 |
|---|---|
| 計算・ひねり | 上半身だけ±45°ひねった所で、胴がねじれた台形になり、腰は正面のまま。横向き（±90°）で、体が線にならず厚みがある。髷が後頭部へ回る |
| 計算・回転切り | 1回転の間、どのコマでも関節が離れない。背中で顔が消え、腕が胴の向こうに回る。重ね順が1コマだけ入れ替わってちらつく所が無い（×0.25 とコマ送りで見る） |
| 計算・速い連撃 | 手前の腕と奥の腕が、振りの途中で正しく入れ替わる |
| ヒデキの4本 | 上と同じ。第1段の「整える」を通して見る |
| 明るい灰の背景 | すき間、はみ出し、関節の角が見えない |

**重ね順のちらつきを防ぐ：** 「どちらが手前か」は、値が逆転しても、差が `U × 0.04` を超えるまでは前のコマの答えを保つ。

**ここを通るまで、部品の絵（第3段）を作り始めない。** 通らない時は、設計資料の3章にある 2.5D への切り替えをヒデキに相談する。

## 第3段：部品の絵

**作る物：絵の決まりの紙、取り込みの道具、人形が絵を使う所。**

### 3-1. 絵の決まりの紙（最初に作ってヒデキへ渡す）

`docs/影の部品の絵の決まり.md` を作る。中身は設計資料の第3段の表に、次を足す。

| 項目 | 決まり |
|---|---|
| 作る物（侍・正面用、最初の12枚） | 頭、胴、上腕（左右で1枚を使い回す）、前腕、手、腿の袴、脛の袴、足、刀、髷、帯の端、肩の当て布 |
| 置き方 | 1枚に1部品。白い背景。部品はまっすぐ縦（付け根が上）。刀は切っ先が上 |
| 余白 | 四方に絵の5%以上 |
| 黒 | `#05080e` 〜 `#12151c`。真っ白や灰色のつやを入れない |
| 光らせる所 | 純粋な赤 `#ff0000` で塗る。細い線か小さな面だけ（面積は部品の1割まで）。目、帯の縁、刃の縁、紋 |
| 左右 | 左右対称でない部品（手、足）は、右用を作る。左は反転して使う |

| 生成の言い方（例） | 「黒い影絵の侍の、右の前腕だけ。籠手と袖口。まっすぐ縦、白い背景、輪郭ははっきり、中の線は少なく、縁に赤い線」 |

### 3-2. 取り込みの道具

`tools/shadow_parts.py`（Pillow を使う。`pip install pillow`）。

1. 白い背景を抜く（白に近い画素を透明に。縁は半透明に）。
2. 赤い所を別の絵に分ける：`…_ink.png`（黒い体。赤は黒に塗り直す）と `…_glow.png`（赤い所だけを白にした物。光らせる時に色を付ける）。
3. 長い辺を 512 に縮める。
4. `assets/ghost_asset_manifest.json` と `data/asset_imports.json` に足す（`CLAUDE.md` の「画像の読み込み」の決まり）。

付け根と先の点（`pivot` `tip`）は、試験場に「部品の点を決める」画面を足して、絵をタップして決める。決めた値を、画面に `shadow_rig.json` の形で出し、写して貼る。

### 3-3. 人形が絵を使う所

- 部品の絵は、`pivot` を付け根の点に、`tip` を先の点に合わせて、回転・拡大して貼る。幅は、長さの倍率と同じにしない：**幅は `U` で決め、長さは骨の長さで決める**（腕が縮んだ時に細くならないように）。
- 絵が無い部品は、仮の形のまま描く（絵が半分しか無くても動く）。
- 胴は、絵を四角形に貼る：肩の線と腰の線の4点へ、絵の4隅を合わせて変形する。Canvas 2D では、三角形2つに分けて `setTransform` で貼る。
- 鬼面：`data/masks.json` の両目の点を、頭の部品の目の位置（`head.eyes: [[x,y],[x,y]]`）に合わせて貼る。面は元の色のまま。正面の時だけ。
- 影の形を作るキャンバスは2枚：`ink`（黒い形）と `glow`（光る所）。第5段で別々に使う。

### できたと言える条件

侍の正面用の絵で、ヒデキの4本と計算の4本を再生し、関節のつなぎ目が目立たない。絵が無い部品（横用）は仮の形で出る。鬼面が顔に付く。明るい灰の背景で粗が無い。ヒデキが iPhone で見て良しとする。

その後で、横用、忍、被り物の絵を作る（設計資料の6章の順）。

## 第4段：揺れる物

**作る物：`js/shadowpuppet.js` の中に、鎖の計算を1つ。** 髷、袖、裾、帯で使い回す。

### 鎖の計算（Verlet 積分）

鎖は、節の点の並び。先頭の節は体に付いている（毎コマ、体の点に置く）。残りの節は：

```
速さ = (今の位置 − 前の位置) × damping
次の位置 = 今の位置 + 速さ + 重力 × dt²
```

そのあと、隣の節との距離を、決めた長さに戻す計算を3回くり返す（先頭は動かさない）。さらに、節が「体から見て決めた向き」から `maxAngle` 以上曲がらないように戻す（暴れを止める）。

| 物 | 付け根 | 節の数 | 節の長さ（U） | damping | 重力（U／秒²） | 絵 |
|---|---|---|---|---|---|---|
| 髷 | 髷の点 | 3 | 0.10 | 0.90 | 6 | 先細りの黒い帯 |
| 袖（左右） | 手首 | 2 | 0.16 | 0.86 | 9 | 肘・手首・鎖の先を結ぶ三角 |
| 裾（左右） | 足首の外側 | 2 | 0.14 | 0.84 | 10 | 脛の部品の下の角を引っぱる |
| 帯の端 | 腰の中点の横 | 4 | 0.12 | 0.92 | 7 | 細い帯 |
| 鉢巻（あれば） | 頭の後ろ | 4 | 0.10 | 0.93 | 5 | 細い帯 |

- 値は `balance.json` の `shadow.cloth` に、物ごとに置く。
- 時間の刻みは固定（1/60秒）。画面のコマが落ちても同じ動きになるよう、たまった時間ぶんをくり返す。
- 影の頭出し（シーク）や最初のコマでは、鎖を「垂れた形」に置き直す（前の位置が遠いと、鎖が飛ぶため）。
- 一時停止・コマ送りの時は、鎖の時間も止める。

### できたと言える条件

速い連撃で髷と袖が体の後ろへ流れ、残心で止まった後に1秒ほど揺れて収まる。回転切りで帯が外へ広がる。どの影でも、鎖が体を突き抜けて反対側へ飛んだり、震え続けたりしない。

## 第5段：光

**作る物：影の形（`ink` と `glow`）から、仕上げの絵を作る所。** ここで、Canvas 2D のままか、WebGL に移すかを決める。

### 先に測る

iPhone で、試験場の「描く時間」を見る。目安は、**影1体で 8ms 以内**（骨格推定と同時に1秒30コマを保つため）。Canvas 2D で下の光を全部入れて 8ms を超えたら、WebGL に移す。

### 重ねる順

| 順 | 物 | Canvas 2D でのやり方 |
|---|---|---|
| 1 | 足元の光 | 両足首の中点の下に、影の色の楕円（横 `U × 1.6`、縦 `U × 0.25`、不透明度 0.25）。`lighter` で重ねる |
| 2 | 立ちのぼる靄 | 体の縁の点から出る粒。今の火の粉を、丸いぼけた絵（暗い藍〜影の色）に替え、大きく（`U × 0.25`）ゆっくり（`U × 0.6`／秒）上へ。数は半分に |
| 3 | 外のにじみ | 今と同じ（影の形の、色を付けた写しを、ぼかして重ねる）。ただし強さを半分にし、全周の細い縁は**やめる** |
| 4 | 影の体 | `ink` をそのまま |
| 5 | 片側の縁の光 | `ink` を、光の向きと**逆**へ `U × 0.035` ずらした物で、`ink` を切り抜く（`destination-out`）。残るのは、光の側の細い縁だけ。それを影の色で塗って、`lighter` で体の上に重ねる |
| 6 | 光る所 | `glow` に影の色を付けて `lighter` で重ねる。明るさは `0.75 + 0.25 × sin(t / 900)`（ゆっくりの呼吸） |
| 7 | 目 | 鬼面が無い時、頭に細い光の目を2つ（正面と横だけ）。直前の位置を4つ覚えて、薄く尾を引く |
| 8 | 刃 | 刃の縁の線。明るさは、切っ先の速さに比例（`U × 8`／秒で最大） |
| 9 | にじみ（bloom） | 5〜8だけを描いた小さなキャンバス（1/4の大きさ）をぼかして、`lighter` で重ねる |

- 光の向き：既定は「画面の左上から」。舞台（第7段）があれば、舞台の定義の `light: [x, y]` を使う。直前0.3秒に技の絵（第6段）が出ていれば、その位置の向きを優先する。
- 影の色：`opts.aura`（青・金）。光る所と縁の光に使う。舞台がある時、外のにじみは舞台の色にする。

### 段階（`shadow.quality`）

| 段階 | 入れる物 |
|---|---|
| `high` | 全部 |
| `mid` | 2 の粒を半分、9 を無し |
| `low` | 1・4・5・6・8 だけ |
| `min` | 古い描き方（`createGhostRenderer`） |

### WebGL に移す時

three.js（`ghost3d.html` と同じ版を同じ所から読む）で、正面からの平行投影の板にする。部品は板1枚ずつ、影の体はまず別の絵（レンダーターゲット）に描き、縁の光・にじみは、その絵を使う小さなシェーダで作る。**部品の定義（`shadow_rig.json`）と、動きの部品、鎖の計算は、そのまま使う。** 書き直すのは「描く所」だけにする。

### できたと言える条件

黒・濃い藍・明るい灰の3つの背景で、影が立体に見える。影の色を青・金・赤にして、どれも破綻しない。縁の光が、体の片側だけにある。iPhone で、`mid` が 8ms 以内。

## 第6段：技の絵

**作る物：`js/shadowfx.js` に `createFx(sheets, cfg)`。** 影の `events` と、動きから、絵を出す。

```js
const fx = createFx(SHEETS, B.shadow.fx);
fx.update(tMs, pose, meta, ghost);      // この時刻までに起きた出来事を拾って、絵を出す
fx.drawBehind(ctx, box);                // 影の後ろに描く物（地面の輪、煙）
fx.drawFront(ctx, box);                 // 影の前に描く物（斬撃の弧、火花）
```

人形の `draw` の中で、後ろ → 影 → 前 の順に呼ぶ。

### 出来事の拾い方

- 影の `events` は `[時刻ms, "swing", 型のid, ダメージ, コンボ数]`。再生の時刻がそれを越えたら1回だけ出す。頭出しで戻ったら、出した印を消す。
- S の振りかどうかは、今は記録に無い。**記録に足す**：`index.html` の `ghostRec.event("swing", j.t.id, dmg, combo)`（2031行あたり）の後ろに、ランク（`sc.rank`）、クリティカルか、技の名前を足す。古い影はそれらが無いものとして扱う。これは判定ではなく記録なので、変えてよい。
- とどめは `result.finisher`（`iai` `hiden` `cut` など）と、最後の振りの時刻。

### 絵の一覧（ヒデキが作る。白で描き、黒い背景。アプリが色を付けて足し算で重ねる）

| 名前 | 中身 | コマ | 出す時 | 置き方 |
|---|---|---|---|---|
| `fx_slash_a.png` | 筆で払ったような弧 | 4×4 | 振り | 刃の通った跡。下の「弧の置き方」 |
| `fx_slash_s.png` | 太く、端が散る弧 | 4×4 | S の振り、クリティカル | 同じ。1.4倍の大きさ |
| `fx_spark.png` | 短い火花が散る | 4×4 | 振りが当たった時（影の前方 `U × 2`） | 切っ先の位置。向きは振りの向き |
| `fx_smoke.png` | 丸い煙がふくらんで消える | 8×8 | とどめの0.2秒後 | 足元。後ろに描く |
| `fx_ring.png` | 地面に広がる輪（斜め上から見た楕円） | 4×4 | 技、秘伝、とどめ | 足元。後ろに描く |
| `fx_gather.png` | 光の粒が1点へ集まる | 4×4 | 居合のとどめの直前 | 足元 |
| `fx_line.png` | 横一文字の光の線が出て消える | 4×2 | 居合のとどめ | 影の胸の高さ、画面の幅いっぱい |
| `fx_mist.png` | ぼけた丸（1コマ） | 1×1 | 立ちのぼる靄（第5段） | － |

1コマの大きさは 256×256。置き場は `assets/images/fx/`。絵が無い間は、線と丸で代わりを描く（絵を待たずに作れるように）。

### 弧の置き方

- 振りの出来事の時刻の前 `0.18秒` から、その時刻までの、切っ先の通った点を取る（動きの部品から、30分の1秒ごと）。
- その点の列の、始めと終わりを結ぶ線を、弧の絵の横幅に合わせる。弧のふくらむ側は、点の列がふくらんでいる側。
- 出してから `0.25秒` で、コマを進めながら消す。色は影の色、S は白に近く。
- 弧の長さが `U × 0.8` より短い時は出さない（小さな動きで絵が出ると安く見える）。

### 画面全体の効き

- S とクリティカル：画面全体に、影の色を 0.12 の濃さで1コマ、次のコマで 0.05。
- とどめ：0.25秒、再生を止める（止め絵）。背景を暗くし、影と絵だけを残す。
- コンボ：コンボ数に応じて、靄の数と明るさを上げる（`1 + min(コンボ, 10) × 0.08`）。

### できたと言える条件

速い連撃で、振りごとに弧が出て、向きが振りと合っている。弧が体の中から出ているように見えない（切っ先の位置から出ている）。絵を全部出しても、iPhone で `mid` が 10ms 以内。

## 第7段：舞台

**作る物：`js/shadowstage.js` に `createStage(def)`、`data/shadow_stages.json`。** 影の書庫の再生・シェア動画・対戦の結果で使う。**戦闘中（カメラの映像の上）では使わない。**

```json
{
  "bamboo_night": {
    "name_ja": "竹林の夜", "name_en": "Bamboo grove at night",
    "color": [90, 140, 255],
    "light": [-0.6, -0.8],
    "layers": [
      { "img": "stage_bamboo_far.png",  "depth": 0.15 },
      { "img": "stage_bamboo_mid.png",  "depth": 0.45 },
      { "img": "stage_bamboo_near.png", "depth": 1.4, "front": true, "blur": true }
    ],
    "ground": 0.86,
    "fog": { "count": 3, "speed": 0.02, "alpha": 0.18 }
  }
}
```

| 項目 | 中身 |
|---|---|
| `color` | この場面の主の色。外のにじみ、霧、縁の光に使う |
| `light` | 光の来る向き（第5段） |
| `layers` | 奥から順。`depth` は、カメラが動いた時にどれだけ動くか（小さいほど奥）。`front` は影の手前に描く |
| `ground` | 地面の高さ（絵の高さに対する割合）。影の足首を、ここに合わせて上下に動かし、大きさも合わせる |
| `fog` | ぼけた横長の雲を、ゆっくり横へ流す |

- 絵：縦 9:16、1080×1920。奥と中は不透明、手前は透明の所がある PNG。置き場は `assets/images/stage/`。**絵が無い間は、上下のぼかし（主の色→黒）と霧だけで代わりにする。**
- カメラ：ゆっくりした拡大縮小（±1.5%、8秒周期）。当たりで揺れ（`U × 0.05`、0.15秒）。とどめで 6% 寄る（0.3秒で寄り、1秒で戻る）。
- 仕上げ：四隅を暗くする。全体に、主の色を 0.06 の濃さで重ねる（色をまとめるため）。

### できたと言える条件

影の書庫の再生で、背景の上の影が1枚の絵に見える。影の足が地面に着いて見える。色がばらばらでない。

## 第8段：決め場面

**作る物：`js/shadowcut.js` に `makeCut(ghost)` と `playCut(cut, canvas)`。**

`makeCut` は、影から場面の並びを作る。

| 順 | 場面 | 選び方 | 長さ |
|---|---|---|---|
| 1 | 構え | 最初の振りの 1.2秒前から | 1.0秒 |
| 2 | 一番の連撃 | コンボが続いた区間のうち、ダメージの合計が一番大きい所。前後 0.3秒を足す | 3〜5秒（長ければ、ダメージの大きい5秒を切り出す） |
| 3 | とどめ | 最後の振りの 0.6秒前から、0.4秒後まで。振りの瞬間に止め絵 0.25秒 | 約1.3秒 |
| 4 | 残心 | とどめの後 | 2.0秒 |
| 5 | 結果 | 妖怪の名前、時間、得点の文字 | 2.0秒 |

- 場面の変わり目：色の面（主の色）が、画面を斜めに 0.2秒で横切る。
- 振りが3つ未満の影（型の影）は、1と4だけにして、間に影の全部を入れる。
- 書き出し：`share.html` と同じやり方（`canvas.captureStream()` と `MediaRecorder`、形式は `share.html` の `pickMime`）。大きさは 720×1280。共有は `navigator.share`。
- 音：`assets/` の効果音（振り、とどめ）を、出来事の時刻に鳴らす。録画に音を入れるには、音の出口を `MediaStreamDestination` につないで、絵の流れと合わせる。iPhone で音が入るかは実機で確かめる。入らなければ、絵だけで出す。

### できたと言える条件

影の書庫で影を選び、「決め場面を作る」を押すと、手を入れずに 10〜15秒の縦動画ができ、iPhone で共有できる。

## 第9段：本体への組み込みと、重さ

| 場所 | 入れ方 | 段階 |
|---|---|---|
| `ghost.html`（影の書庫） | 再生を、動きの手当て＋人形＋技の絵＋舞台にする。「決め場面を作る」のボタン | 自動 |
| `index.html`（一騎打ち・仇討ち） | 最速の影の再生（結果の画面から） | 自動 |
| `index.html`（影との対戦。`docs/設計_シェアと影.md` の③。まだ無い） | 相手の影を人形で描く。舞台なし | `mid` 以下 |
| `share.html` | 決め場面の動画 | `high` |

### 段階を自動で選ぶ

最初の2秒、`mid` で描いて、描く時間の平均を測る。

| 平均 | 段階 |
|---|---|
| 5ms 未満 | `high` |
| 5〜9ms | `mid` |
| 9〜14ms | `low` |
| 14ms 以上 | `min`（古い描き方） |

骨格推定と同時に動かす場面（戦闘中）では、1段下げる。選んだ段階は、設定の画面で手でも替えられるようにする（`S.shadowQuality`。本体のセーブに足す）。

### 絵の読み込み

- 部品・技・舞台の絵は、使う場面に入る時に読む（表紙では読まない）。
- 読めなかった絵は、仮の形で描く。絵が無くても止まらない。

### できたと言える条件

iPhone で、影の書庫・一騎打ちの結果・シェアが新しい影で動く。戦闘中に、骨格推定のコマ数（画面下の診断の行）が、入れる前と比べて1割以上落ちない。

## 困った時

| 起きた事 | 見る所 |
|---|---|
| 影が出ない | 試験場の下の赤い枠。`poseAt` が返す点の数。`aspect`（影に無ければ 0.75） |
| 左右が逆 | 画面の x は `1 - x`。向きの符号は「本人の左がカメラへ寄ると＋」 |
| 横や背中で崩れる | `meta.facing` が出ているか（奥行きの無い影では出ない）。胴の半幅の式 |
| 重ね順がちらつく | 「差が `U × 0.04` を超えるまで前の答えを保つ」が入っているか |
| 鎖が飛ぶ | 頭出しの時に置き直しているか。時間の刻みが固定か |
| 重い | 影の形のキャンバスを、画面いっぱいではなく、影を囲む四角だけにする。にじみを1/4の大きさで作る |
| 絵と骨がずれる | `pivot` と `tip`。幅は `U`、長さは骨の長さで別々に決めているか |
