# 提出資料の一覧（どのチャットに何を出すか）

2026-11-05 作成。迷ったらこの表を見る。

GitHubにあるファイルは https://github.com/hizashi001/suburi-bugeicho から開ける。ファイルを開き、右上の「…」から「Download」で保存できる。

---

## A. 本体の開発（通常のDevのClaude Code）

アプリ本体（妖怪退治・登頂・TABATA・鬼面のシェア・影・3Dの影・刀の学習データ作り）を進めるチャット。

**始めるとき**

| 出すもの | 場所 | 備考 |
| --- | --- | --- |
| （ファイルの提出は要らない） | 全部GitHubにある | リポジトリを開いたClaude Codeで始める |
| 最初のひとこと | — | 「`CLAUDE.md` と `docs/引継ぎ_全体.md` を読んで、続きから進めて」 |

**途中で出すもの**

| 出すもの | いつ |
| --- | --- |
| iPhoneのスクリーンショット・画面の録画 | 試した結果を伝えるとき（赤いエラーの枠が出たら必ず） |
| 気づいたことのまとめ | 1件ずつではなく、まとめて1回で |
| 新しい画像・効果音・BGM | 先にGitHubの決まったフォルダへ上げる（最後に緑の「Commit changes」）。そのあと「入れた。処理して」と伝える |

## B. 刀を見つけるAIのチャット（新しく始める）

カメラの映像から切っ先・鍔・柄頭を見つけるAIを作るチャット。

**始めるとき**

| 出すもの | 場所 | 備考 |
| --- | --- | --- |
| `docs/引継ぎ_刀検出AI.md` | GitHub | **最初に必ず**。最初のひとこと：「この資料を読んで、刀を見つけるAIを作りたい」 |
| `labels.json` | 本体のチャットで受け取ったファイル（手元に保存した物） | 14コマに付けた最初の手本の印 |
| `labeled.jpg` | 同上 | 上の印を描き込んだ確認用の画像 |
| WORKOUTの動画（例：`1105.mp4`） | ヒデキの手元 | 手本作りに使う動画。**顔が映るので公開の場所には置かない** |
| `swordlab.html` で書き出したzip | ヒデキの手元（Google Driveなど） | 撮って印を付けたデータ。たまったら渡す |

**本体のチャットへ戻るとき**（`docs/引継ぎ_刀検出AI.md` の5章）

| 持ってくるもの |
| --- |
| 学習済みのモデルのファイル（ブラウザで読める形） |
| `js/swordtrack.js`（決めた形どおりの部品の全文） |
| 試験ページ（iPhoneで切っ先と柄頭が点で出るページ） |
| 結果の報告（iPhoneでの速さ、精度、苦手な場面） |
| 利用規約のまとめ（商用で使ってよいか） |
| 学習データの置き場所と、作り直す手順 |

本体のチャット（A）で「`docs/引継ぎ_刀検出AI.md` の結果を持ってきた。組み込んで」と伝える。

## C. 侍の旅のチャット（ドット絵のハクスラ、続いているチャット）

**始めるとき・続けるとき**

| 出すもの | 場所 | 備考 |
| --- | --- | --- |
| `tabi/HANDOFF.md` | GitHub（または手元の `ghost_main.zip` の中） | 最初に読ませる |
| `ghost_main.zip` | ヒデキの手元 | ゲーム本体の一式。ふだんはこれだけ |
| `ghost_vfx_src.zip` | ヒデキの手元 | 新しいVFXを足すときだけ |
| `ghost_chara.zip` と `tabi/CHARA_HANDOFF.md` | ヒデキの手元／GitHub | 新しいキャラを作るときだけ |

注意：ページを組み立て直すとき、`shell_head` の先頭の `<meta charset="utf-8">` を消さないよう伝える（消えるとGitHubで文字化けする）。

**本体のチャットへ戻すとき**

| 持ってくるもの | 伝えること |
| --- | --- |
| 新しい `ghost_main.zip`（必要なら他のzipも） | 本体のチャット（A）で「`tabi/` を更新して」 |

## D. 素材を作るとき（画像・音）

| 作る前に見るもの | 場所 |
| --- | --- |
| 何が足りないか | `docs/素材の登録状況.md`（GitHub） |
| 名前の決まり | `CLAUDE.md` の「画像の読み込み」、`docs/効果音の入れ方.md` |

作ったら：GitHubの決まったフォルダへ上げる → 本体のチャット（A）に「入れた。処理して」（背景抜き・軽量化・一覧の更新をしてもらう）。
