## 得物と刀は別のもの

| 呼び名 | 中身 | 役割 |
| --- | --- | --- |
| 得物 | 実際に手に持つ物（木刀、居合刀、箒、木製の短刀など） | 重さの選択、倍率の自動調整、ランキングの階級、侍か忍かを決める |
| 刀 | ゲームの中で拾い、集める刀と短刀 | 装具。ステータス、図鑑、組み合わせ、揃いボーナス |

箒で振っていても、ゲームの中では名刀を差していて構いません。

## 刀の仕組み

### 4つの部品

| 部品 | 主性能 |
| --- | --- |
| 刀身 | 与ダメージ |
| 鞘 | とどめの倍率（居合） |
| 鍔 | 受けるダメージの軽減 |
| 柄 | S判定のときの与ダメージ |

部品は1つずつ拾い、1つずつ付け替えられます。等級、主性能の幅、付与効果、「極」、希少効果、合計の上限は、企画書の「装具のステータス」と同じ決まりです。

### 刀と短刀の個性

得物が刀の類なら侍、短刀の類なら忍です。侍は刀の部品だけ、忍は短刀の部品だけを装備できます。

| 種類 | 個性 | 稼ぎ方 |
| --- | --- | --- |
| 刀（侍） | S判定の倍率×1.15、とどめの倍率×1.10 | 型の正確さ |
| 短刀（忍） | 一撃×0.80、COMBOの受付×1.30、回避の受付×1.15。前の命中から1.5秒以内に当てるたびに与ダメージ+5%（上限+30%、途切れたら0） | 手数と速さ |

この個性も装具と同じく**武士部門だけ**で効きます。侍部門は素の実力の勝負です。

### 名物と無銘

- **無銘**：等級（数打〜最上大業物）の付いた、名前のない部品。どの妖怪からも落ちる
- **名物**：名前のある一振りの部品。最上大業物より一段上の扱いで、主性能は+18〜22%。その刀に合った付与効果が1つ固定、残り2つは抽選
- 名物の部品は、決まった相手からしか落ちない。ボスからは30%、通常の妖怪からは3%で、4部品のどれか1つ。特別な条件のものは、条件を満たしたときに1つ確定
- 同じ部品が重なっても、付与効果の数値は毎回違う。より良い一品を求めて倒し続ける理由になる

### 揃いボーナス

| 揃い | 効果 |
| --- | --- |
| 同じ名物を2部品 | 与ダメージ+5% |
| 同じ名物を3部品 | 与ダメージ+10%（2部品の効果と入れ替わる） |
| 同じ名物を4部品 | その刀の銘効果（下の一覧） |
| 違う名物を4部品（寄せ拵え） | 獲得EXP+10% |

## 図鑑と見せ方

2Dでも達成感を出すために、次の4つを組み合わせます。

1. **刀剣帳**：名物ごとに1ページ。4部品の枠が影の形で並び、拾った部品から埋まっていく。由来とひとことはここで読める。手放した部品も「見た」記録は残る
2. **拵えの表示**：今装備している4部品を組み合わせた一振りを、刀掛けに掛けた姿で見せる。部品の画像を重ねると位置がずれやすいため、組み上がった姿はコードで描く方針（`swords.json` の `look` と等級の色を使う）。部品の画像は図鑑と拾ったときの演出に使う
3. **揃った瞬間の演出**：4部品がそろうと、部品が集まって一振りになり、銘が刻まれ、師範の声が入り、その刀の一枚絵（`sword_NN_id_full.png`）が開く
4. **戦闘中**：装備した刀身の色（`look.aura`）が、影絵の太刀筋の光の色になる

## 由来とひとこと

史実の刀の由来は、伝承として広く知られている内容だけで書いています。オリジナルの刀は、このゲームの中の言い伝えです。ヒデキが確認し、違和感のあるところを直します。英語などの訳は、文言の言語ファイルに入れるときに作ります。

**1. 童子切安綱（どうじぎりやすつな）**　史実・大原安綱（伯耆国）

- 由来：源頼光が大江山の鬼の頭領・酒呑童子の首を落としたと伝わる太刀。天下五剣の一つに数えられる。
- ひとこと：「鬼の名を聞けば、鞘の内で刃が鳴る。」

**2. 髭切（ひげきり）**　史実・不詳（源氏重代の宝刀）

- 由来：試し斬りで罪人の髭まで断ったことから名付けられた源氏の宝刀。渡辺綱が一条戻橋で鬼の腕を斬った刀とも伝わる。
- ひとこと：「鬼の腕を断った刃は、二度目を逃さない。」

**3. 蜘蛛切（くもきり）**　史実・不詳（源氏重代、膝丸とも）

- 由来：試し斬りで膝まで断ったことから膝丸と呼ばれ、病床の源頼光が土蜘蛛を斬って蜘蛛切と改めたと伝わる。髭切と対をなす源氏の宝刀。
- ひとこと：「糸が張られる前に、気配を断つ。」

**4. 獅子王（ししおう）**　史実・不詳

- 由来：源頼政が御所に現れた鵺を射落とした褒美として、帝から賜ったと伝わる太刀。
- ひとこと：「雷雲の奥に潜むものほど、よく怯む。」

**5. 小狐丸（こぎつねまる）**　史実・三条宗近

- 由来：稲荷明神の化身の狐が相槌を打ち、三条宗近が鍛え上げたと謡曲「小鍛冶」に語られる太刀。

## 実装メモ

- 名物のデータは `data/swords.json` を正本にする。由来やひとことを直すときもこのファイルを直す
- 刀の部品と防具を合わせて、装具の保存枠は企画書どおり無料30
- 抽選は今は端末の中でよいが、種（seed）を受け取る独立した部品にしておく（ランキングに関わるため、後でサーバーへ移す）
- 刀の部品の画像は `assets/images/sword/` に置く。まだないものは、部品の形を描いた仮の印で代わりに表示する
