# 注文書：筆の素材（AIで作る）

2026-11-17。墨絵の影（`docs/設計_影の3D.md` 第3D-2.8・2.9段）で、今は計算で作っている筆の筋・刀の軌道・飛沫・煙を、本物らしい素材に差し替えるための注文書。

## 共通の決まり

- **真っ白の背景に、黒い墨だけ。** 紙の模様・文字・落款（はんこ）・影・枠は入れない（白は描く側で透明にする）
- 形式は PNG。ファイル名は英小文字・数字・アンダーバーだけ（下の表のとおり）
- 置き場所：`assets/images/shadow/`
- 置いたら `data/asset_imports.json` に1件足し、`python3 tools/asset_list.py` を回す
- 何枚か作って、いちばん良い物を選んでよい

## 作る物（10枚）

### 1. 刀の軌道の一払い（4枚）

- ファイル名：`shadow_brush_sweep_01.png` 〜 `shadow_brush_sweep_04.png`
- 大きさ：2048×512（横長）
- 指示文：

```
a single horizontal sumi-e ink brush stroke, one fast sweeping stroke from left to right, thick at the start and splitting into dry bristle streaks at the end, black ink on pure white background, no paper texture, no text, high resolution
```

### 2. 体の中のかすれ（2枚）

- ファイル名：`shadow_brush_dry_01.png`、`shadow_brush_dry_02.png`
- 大きさ：1024×1024（正方形）
- 指示文：

```
seamless dry-brush sumi ink texture, many fine parallel bristle streaks with gaps, black ink on pure white background, tileable, no text
```

### 3. 飛沫（1枚）

- ファイル名：`shadow_brush_splat_01.png`
- 大きさ：2048×2048（正方形）
- 指示文：

```
sheet of separate sumi ink splatter drops and flicks of many sizes, some with thin tails, scattered with space between them, black ink on pure white background, no text
```

### 4. 巻く煙（3枚）

- ファイル名：`shadow_brush_smoke_01.png` 〜 `shadow_brush_smoke_03.png`
- 大きさ：1024×1024（正方形）
- 指示文：

```
black ink dropped in water, swirling smoke-like ink plume rising and curling, soft edges and fine wisps, black on pure white background, no text
```
