# 効果音とBGMの入れ方

## 仕組み

今の効果音は、すべてアプリの中で合成している（録音のファイルは無い）。
決まった名前の mp3 を `assets/sounds/` に置くと、その音が合成の音の代わりに鳴る。置いていない音は、合成の音のまま鳴る。BGMは合成の代わりが無いので、ファイルを置いたときだけ流れる。

1. 下の表の名前で mp3 を作る（例：`hit_katana.mp3`）
2. `assets/sounds/` に入れて GitHub に上げる
3. iPhoneでページを開き直す（効果音は最初に画面を触ったときに読み込まれる）

1つずつ差し替えて試せる。コードを触る必要はない。

## 用意してほしい順番

手応えに一番効くものから。上の3つだけでも、振る気持ちよさが大きく変わる。

1. `hit_katana` / `hit_tanto`（当たった音。COMBOで高くなる）
2. `crit_katana` / `crit_tanto`（クリティカル専用の音）
3. `slay`（撃破の音）
4. 師範の声（`voice_` で始まる5つ）
5. BGM（`bgm_run` から）
6. 残りの効果音

## BGM（ファイルを置いたときだけ流れる）

どれも**繰り返し再生する**ので、頭と尻が自然につながるように作る。長さは1〜2分、ファイルは2MB以内が目安。

| ファイル名 | 流れる場面 | 雰囲気 |
| --- | --- | --- |
| `bgm_title.mp3` | 表紙 | 静かな和楽器（尺八・琴） |
| `bgm_menu.mp3` | 身支度・型の登録・妖怪退治や登頂の入口など、表紙以外のメニュー | 待っていても疲れない曲。無ければ `bgm_title` が流れる |
| `bgm_run.mp3` | 妖怪退治の戦闘 | 太鼓が主役で、素振りの速さに合う一定のテンポ（BPM 110〜130） |
| `bgm_boss1.mp3` | 5階・15階・25階…のボス | 低い太鼓と緊張感 |
| `bgm_boss2.mp3` | 10階・20階・30階…のボス | `bgm_boss1` と違う曲。無ければ `bgm_boss1` が流れる |
| `bgm_climb.mp3` | 登頂 | 少しずつ高まる、山を登る感じ |
| `bgm_tabata.mp3` | TABATA | WORKOUTで使っている曲をそのまま。**繰り返さず1回だけ流し、曲の6.33秒目から1本目の20秒が始まる。** 20秒・10秒の区切りは曲に合わせて進む（`config/balance.json` の `tabata.musicLeadSec`） |
| `bgm_shop.mp3` | 買い物画面（まだ画面が無いので、作ったときに使う） | |

決定の音：`kettei.mp3`（妖怪退治・登頂・TABATAを始めたとき。BGMの上に重ねて鳴る）

BGMは、効果音が聞こえるように小さめにかける（音量は `config/balance.json` の `sound.bgmVol`）。

## 作り方の目安

- 形式は mp3（iPhoneのSafariで確実に鳴る）。効果音はモノラル、44.1kHz、128kbps で十分
- 頭の無音は切る。遅れて聞こえると、斬った手応えがずれる
- 音量はそろえる（ピークを -1dB 程度にノーマライズ）。環境音とBGMは小さめに作る
- 効果音は1つ100KB以内が目安。読み込みが遅くなるため

## 音の手に入れ方

- **自分で録る**：師範の声と息遣い、木刀の素振りの風切り音は、本人のものがいちばん合う
- **素材サイト**：効果音ラボ、魔王魂、OtoLogic など。**商用利用（ストア公開）が許されているか、クレジット表記が要るかを必ず確かめる**。後でストアに出すので、そこで使えない素材は最初から使わない
- **生成**：音や曲を生成するサービスを使う場合も、商用利用の条件を確かめる

使った素材の出典と条件は、下の表に書き足しておくと、ストア申請のときに困らない。
