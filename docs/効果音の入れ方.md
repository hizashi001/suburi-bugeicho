# 効果音の入れ方

## 仕組み

今の音は、すべてアプリの中で合成している（録音のファイルは無い）。
録音した音を `assets/sounds/` に決まった名前で置くと、その音が合成の音の代わりに鳴る。置いていない音は、今の合成の音のまま鳴る。

1. 下の表の名前で mp3 を作る（例：`swing_katana.mp3`）
2. `assets/sounds/` に入れて GitHub に上げる
3. iPhoneでページを開き直す（最初にカメラを始めたときに読み込まれる）

1つずつ差し替えて試せる。コードを触る必要はない。

## 作り方の目安

- 形式は mp3（iPhoneのSafariで確実に鳴る）。モノラル、44.1kHz、128kbps で十分
- 頭の無音は切る。遅れて聞こえると、斬った手応えがずれる
- 音量はそろえる（ピークを -1dB 程度にノーマライズ）。環境音だけは小さめに作る
- 1つのファイルは小さく（100KB以内が目安）。読み込みが遅くなるため

## 音の手に入れ方

- **自分で録る**：師範の声（伏せよ・受けよ・跳べ・とどめ・残心）は、本人の声がいちばん合う。iPhoneのボイスメモで静かな部屋で録り、mp3に書き出す。木刀の素振りの風切り音も録れる
- **素材サイト**：効果音ラボ、魔王魂、OtoLogic など。**商用利用（ストア公開）が許されているか、クレジット表記が要るかを必ず確かめる**。後でストアに出すので、そこで使えない素材は最初から使わない
- **生成**：音を生成するサービスを使う場合も、商用利用の条件を確かめる

使った素材の出典と条件は、このファイルの下に書き足しておくと、ストア申請のときに困らない。
