# NINJA SAMURAI WORKOUT アプリ企画書

Oct 28, 2026 · @ヒデキ

## 要約

**師範の影、世界の影、過去の自分の影と戦う、侍特化の素振りアプリ**です。Instagramの「NINJA SAMURAI WORKOUT」と連動し、iPhoneとAndroid向けに公開します。アプリ名は「NINJA SAMURAI WORKOUT: GHOST」です。

- **芯**：影と戦う。師範の動きを半透明グレーの影にし、自分の動きを追いつかせる
- **主軸**：1体約3分の妖怪退治。毎回とどめと得点があり、次々に進める
- **毎日の登頂**：毎日Lv1から、一日でどこまで登れるかを世界で競う
- **特別な時間は日本時間22時**：動画の投稿、一斉討伐の解放、登頂の切り替えをそろえる
- **二部門**：ドロップ運が絡む武士部門と、生身で勝負する侍部門。ランキングは歴代・週間・今日
- **収益**：遊びは無料。技の伝書（1技100円程度）、快適さの拡張、鬼面、師匠に茶を出す心付けを買い切りで売る

無手モード、クラス、15分コースは作りません。武器は刀か短刀かで侍か忍かが決まるだけに絞ります。

## コンセプト：影と戦う

熱中の理由は「強敵がいること」と「己の成長を実感すること」です。この二つを、影という一つの仕組みで同時に生みます。

| 影 | 正体 | 役割 |
| --- | --- | --- |
| 師範の影 | シマハラヒデキの太刀筋 | 最初の強敵。見本であり、追い越す目標 |
| 世界の影 | ランキング上位やフォロワー仲間の記録 | 顏も知らない強敵。影レースの相手 |
| 過去の自分の影 | 一週間前の自分の記録 | 追い越した瞬間に成長が目に見える |

**影の段階**

1. 見取り稽古：師範の影が少し先を動き、それをなぞる
2. 影追い：同じ速さで並んで振る。ズレが小さいほど高得点
3. 影斬り：影より速く正確に振る。追い越した瞬間、影が斬られて散る

**影は動画ではなく骨格のデータ**で持ちます。30秒の技で数百KB程度の見込みで、同じ長さの動画のおよそ百分の一です。師範の影はアプリ自身の録画機能で撮り、プレイヤーの判定と同じ骨格推定で作ります。同じものさしで比べるためです。

- 影はプレイヤーの肩幅と身長に合わせて伸び縮みさせる
- フロントカメラは鏡像になるため、「鏡の中の師範を真似る」向きで描く
- 影の刀の描き方は、今のコードでの刀の向きの扱いに合わせる

## 想定プレイヤーと届け方

最初に届けるのは**海外の侍好き**です。自宅で、空いた時間に3分ずつ遊ぶ姿を想定します。コア層には、登頂、侍部門、影斬りという奥行きを用意します。

- 入口はInstagramの「NINJA SAMURAI WORKOUT」。視聴者は海外が約4分の3で、想定プレイヤーと重なる
- アプリ名にも「NINJA SAMURAI WORKOUT」のブランド名を使う。「あのワークアウトのアプリ版。カメラが採点してくれる」として伝える
- 動画で実証された「専門性より汎用性」「NO SWORD NEEDED」を引き継ぐ。木刀がなくても、棒やほうきで遊べる
- 師範は鬼面の姿で登場する。動画と同じ姿なので、視聴者には見覚えがある
- 海外のジムで動画を元にしたクラスが開かれている。曲に合わせて振る作りは、こうしたクラスでも使える

## 遊びの全体像

主軸は1体約3分の妖怪退治です。そこに、毎日の登頂、22時の一斉討伐、影レースを重ねます。

| モード | 中身 | 競うもの |
| --- | --- | --- |
| 妖怪退治 | 1体約3分。何体でも続けて遊べるハクスラ | 妖怪ごとの得点 |
| 登頂 | 毎日Lv1から。一日でどこまで登れるか | 到達した階 |
| 22時の一斉討伐 | 動画の投稿と同時に解放される大妖怪 | 倒した数と速さ |
| 影レース | 同じ妖怪に、他人や過去の自分の影と同時に挑む | どちらが先に倒すか |

### 1体3分の流れ

1. 遭遇（約5秒）：妖怪が現れ、名前と今日の秘伝が声で告げられる
2. 戦闘（約2分15秒）：曲のカウントに乗って、回避、攻撃、怖み。秘伝の技はクリティカル
3. とどめ（約15秒）：HPが0になったら「とどめを刺せ」。居合か秘伝のコンボから、残心3秒
4. 結果（約15秒）：得点、順位、ドロップ。「次の妖怪へ」か「ここで終える」を選ぶ

結果画面を短くしてすぐ次へ進めるのが、「あと1体だけ」を生むコツです。腕が元気なうちはサクサク進める手応えにします。

### とどめと残心

とどめの完成度で得点に倍率がかかり、最終得点が跳ね上がります。居合、または指定のコンボの後に、3秒の残心（静止）を求めます。残心はカメラで判定しやすく、海外の侍好きが「本物らしさ」を感じる部分です。とどめの間だけは影を消し、自分ひとりの力で決める演出にします。

### 登頂

- 毎日、日本時間22時に新しい山が始まる。全員Lv1から
- 一日に何度でも挑め、前回の続きから登れる
- 戦闘の途中で休むと、その敵で得た点は0になり、敵のHPも満タンに戻る。休むなら倒した直後がおすすめ。休憩とみなすのは、アプリを終了したときと、1分以上コンボが止まったとき。プレイヤーがカメラに映ったまま、電話などでアプリが不意に裏に回った場合は「保留」とし、戻れば続きから遊べる
- 茶屋は置かない。休憩は各自が好きなペースで取る
- 5階、10階などのボスは全員同じ
- 当たりの妖怪として**座敷童**を置く。出会うと画面全体が金色に光り、鈴の音が鳴る

時間のある人が有利になるのは当然とします。筋力がある人は短い時間でも高く登れ、姿勢が加点になるので丁寧な人も登れます。やり直しがきかない点は全員同じです。

### 22時の一斉討伐

ワークアウト動画の投稿と同時に、今夜の大妖怪を解放します。何体倒せたかを動画のコメント欄に書いてもらい、盛り上がりを作ります。日本時間22時は、インドネシアで20時、インドで18時30分、イランで16時30分（冬時間）です。アプリ内では各自の現地時刻で表示します。

- 大妖怪は、ボスの表から毎晩抽選する
- とどめの技は、必ず今週の秘伝にする。「今週の動画の技で、今夜の大妖怪にとどめを刺す」と言い切れる
- 戦闘中の技は、登録済みの技の表から毎晩抽選する
- この仕組みなら、新しく作るコンボは週に1つで回る

### 影レースとマッチング

世界のプレイヤーとの対戦は、遊ぶ人の数に合わせて3段階で広げます。

1. 公開時：影レース。実在のプレイヤーが残した影と競う。名前と国を表示し、相手が影であることは正直に示す
2. 22時の一斉討伐の時間だけ、生のマッチングを開く
3. 遊ぶ人が増えたら常時マッチング。数秒探して相手がいなければ、近い腕前の影に切り替える

判定はそれぞれの端末で行うため、通信でやり取りするのは妖怪のHPの減り具合程度です。多少の通信の遅れは問題になりません。難しいのは技術より、同じ時間に遊ぶ人の数を確保することです。

## 部門とランキング

どのモードにも、**装具や運が絡む武士部門**と、**生身で勝負する侍部門**があります。ライト層は武士、手間を省きたい人は侍、コア層は両方を遊ぶ想定です。戦う前に部門を選び、侍部門では装具を外して挑む演出を入れます。

|  | 武士部門 | 侍部門 |
| --- | --- | --- |
| 妖怪退治 | 集めた装具が効く | 装具なし |
| 登頂：持ち込み | なし（その日に拾った装具だけ使う） | なし |
| 登頂：出現する妖怪 | 人によって変わる（抽選の表は全員同じ） | 全員同じ |
| 登頂：ドロップ | 人によって変わる（抽選の表は全員同じ） | なし |
| 登頂：ボス | 全員同じ | 全員同じ |

武士部門の出現を固定しないのは、妖怪ごとに弱点の斬撃があるためです。固定すると、その日の弱点が得意な型だった人が有利になります。座敷童に出会えた日は、もう少し頑張ろうという原動力になります。

### ランキング

- 歴代・週間・今日の3つ。歴代の強い影が居座っても、新しい人は今日と週間で上位を狙える
- 妖怪ごと、登頂の到達階、国ごとに並べる。世界1位は無理でも「自分の国でこの妖怪の1位」を狙える
- 表示名にInstagramのアカウント名を出せる選択肢を用意する。「フォロワーの中で誰が一番か」がコメント欄の話題になる
- 週の初めにInstagramで「先週の世界1位」を発表する
- ランキングは公開時から入れる

### 不正対策

- 上位の記録には、とどめの骨格データを添えて保存する
- 人間に不可能な速さの記録だけを自動で弾く。上手い人を誤って弾かないよう、武器の重さとの照合はしない
- 上位の影は誰でも再生できる。ごまかしにくくなり、そのまま影レースの相手にもなる
- おかしな記録は通報できる。管理者が記録を消し、その人をランキングから外せる管理画面を作る

## 武器：侍と忍

武器は刀と短刀の2種類だけです。メインの武器が刀なら侍、短刀なら忍になります。無手やクラスは作らず、侍に特化します。

|  | 侍 | 忍 |
| --- | --- | --- |
| 武器 | 刀（木刀、居合刀、棒でも可） | 短刀 |
| 持ち味 | 型の正確さ | 手数と速さ |
| 怖みの時の指示 | 指定の型、または二連 | 左右交互の連撃を指定回数 |

### 重さによる自動調整

武器を選択肢（素手・タオル／箒／木刀／アルミ居合刀 400g／合金居合刀 850g／重り付き／その他）から選ぶと、ダメージ倍率とCOMBOの受付時間が自動で調整されます。

- 重い武器：一撃の倍率が高く、COMBOの受付が長い（振りが遅くなるぶんを補う）
- 軽い武器：倍率は控えめで、受付は短い。その代わり手数で稼ぐ
- どの重さでも同じように遊べることを目標にし、具体的な式は実機で試しながらコード側で詰める
- 武器の登録は2つまで無料。3つ目からは買い切りで拡張

重さは自己申告なので、ランキングで有利になるように重めに入力する人が出る恐れがあります。そこでランキングは階級別（軽量級：素手・タオル・箒、中量級：木刀・アルミ居合刀、重量級：合金居合刀・重り付き）にし、不正対策は「部門とランキング」のとおり自動の除外、通報、管理者による削除で補います。武器の写真登録は、振るときに持ち替えられると防げないため行いません。

## 装具のステータス（ハクスラ要素）

同じ名前の装具でも、拾うたびに数値が違う作りにします。「もっと良い一品が出るかもしれない」が、妖怪を倒し続ける理由になります。数値はすべて初期値で、テストで調整します。

装具が効くのは**武士部門だけ**です。侍部門では装具を外して戦います。

### 等級と出やすさ

| 等級 | 落ちる割合 | 主性能の幅 | 付与効果の数 | 希少効果 |
| --- | --- | --- | --- | --- |
| 数打 | 55% | +1〜3% | 0 | なし |
| 業物 | 28% | +3〜6% | 1 | なし |
| 良業物 | 12% | +6〜10% | 2 | なし |
| 大業物 | 4% | +10〜15% | 3 | 10%の確率で1つ |
| 最上大業物 | 1% | +15〜20% | 3 | 必ず1つ |

- 大将の妖怪は等級が1段上がりやすく、金色の妖怪は良業物以上が必ず落ちる
- ボスは大業物以上を必ず1つ落とす。座敷童は30%で最上大業物を落とす

### 主性能（部位で決まる）

| 部位 | 主性能 |
| --- | --- |
| 鉢金 | とどめの倍率 |
| 籠手 | COMBOの受付時間 |
| 胴 | 最大HP |
| 脛当 | 回避の受付時間 |
| 鍔 | 与ダメージ |
| 御守 | ドロップ率 |

### 付与効果（ばらつく部分）

下の表から重複なしで抽選し、数値も幅の中で毎回抽選します。等級が上がるほど幅が広がります（業物×1.0、良業物×1.3、大業物×1.6、最上大業物×2.0）。

| 付与効果 | 基本の幅 |
| --- | --- |
| 与ダメージ | +2〜5% |
| S判定のときの与ダメージ | +3〜8% |
| 秘伝の技の与ダメージ | +4〜10% |
| COMBO倍率の上限 | +0.1〜0.3 |
| 怯みゲージの減り | +3〜8% |
| とどめの倍率 | +2〜6% |
| 回避の受付時間 | +3〜8% |
| 受けるダメージ | −2〜5% |
| 最大HP | +3〜8% |
| 獲得EXP | +3〜8% |
| ドロップ率 | +2〜6% |
| 金色の妖怪の出現率 | +5〜15% |

- 抽選した数値が幅の上位5%に入ったら「極」の印を付け、金色の文字で見せる。同じ装具でも「極」が付いた一品は特別になる
- 装具全体で合計できる上限を設ける：与ダメージ系は+80%まで、受けるダメージは−40%まで、受付時間は+40%まで。装具だけで勝てるようにはしない

### 希少効果（大業物・最上大業物だけ）

| 希少効果 | 内容 |
| --- | --- |
| 残心の極み | 残心が3秒ではなく2秒で成立する |
| 二の太刀 | とどめの倍率を2回抽選し、高い方を採る |
| 不動 | 1戦に1回、被弾を無効にする |
| 韋駄天 | 回避に成功すると、次の一振りの与ダメージ+25% |
| 秘伝伝授 | 今週の秘伝のクリティカル倍率+30% |
| 連撃 | 1戦に1回、ミスしてもCOMBOが途切れない |
| 鬼気 | HPが30%以下のとき、与ダメージ+30% |
| 招福 | 座敷童の出現率が2倍 |
| 金運 | 金色の妖怪の出現率+50% |

- 希少効果を持つ装具は、名前の頭に効果名が付く（例：「不動の大業物・胴」）
- 同じ希少効果は重ねて付けても1つ分しか効かない

### 持ち物

- 装具の保存枠は無料で30。買い切りで30ずつ増やせる
- 登頂（武士部門）で拾った装具はその日だけ使え、22時の切り替えで消える。妖怪退治で拾った装具は残る
- ランキングに関わる抽選は、不正を防ぐためサーバーで行う（またはサーバーが渡す種で行う）

## 秘伝と動画の連動

動画で新しい技を出すたびに、同じ技がアプリの「秘伝」になります。動画を作るときにアプリ用のデータも一緒に作るので、更新を高い頻度で続けられます。

1. 動画で新しい技を公開する（日本時間22時）
2. その技が「今週の秘伝」になる。1週間は誰でも使え、使うとクリティカルになる
3. 今日の条件として、「秘伝を5回S判定せよ」「とどめは秘伝で」などの課題が出る
4. 次の秘伝に入れ替わったら、過去の秘伝は伝書（買い切り）で迎えられる

動画を見て「やってみたい」と思った人が、その場で無料で試せます。公開中の秘伝は誰でも使えるので、ランキングが「買った人が有利」になりません。

### 技のデータ

技は2層で持ちます。

| 層 | 中身 | 役割 |
| --- | --- | --- |
| 譜面 | 「袈裟→逆袈裟→横薙ぎ」などの型の並びと、それぞれのタイミング | 判定に使う。今ある型の登録を使える |
| 影 | 師範の骨格の動き | 見本と、追いかける目標として描く |

### 曲に合わせて振る

動画の技には、すでに「Bait → Beat Down → Thrust」のようなビート表記があり、BGMのカウントに乗っています。そのままリズムゲームの譜面になります。動画と同じSUNOの曲で、カウントに合わせて振ります。リズムがあると、ジムのクラスのように大勢でそろって振る場でも使えます。

技の名前は動画と同じ「漢字＋ROMAJI＋英語の異名」（例：誘蛾 YUUGA "the moth lure"）で表示します。

## 演出：離れていても分かる

スマホを立てて2〜3m離れると、画面の文字は読めません。そこで**音を主役にし、画面は色と形だけで伝えます**。画面を見なくても、師範の号令と音だけで遊べることが目標です。

**基本の文法**：赤＝よけろ、金＝今斬れ、緑＝成功。画面いっぱいに半透明の図形を出し、音も種類ごとに変えます。

| 敵の動き | やること | 画面 | 音 |
| --- | --- | --- | --- |
| 薙ぎ払い | しゃがむ | 下半分に赤い下向きの大矢印 | 低い「ブォン」 |
| 振り下ろし | 剣を立てて受ける | 中央に赤い盾の形 | 金属の「キーン」 |
| 突進（右から） | 左へステップ | 左半分に赤い左向きの大矢印 | 右から左へ移る音 |
| 突進（左から） | 右へステップ | 上の左右反転 | 左から右へ移る音 |
| 怖み（攻め時） | 指定の型で斬る | 金色の太い矢印で型の向き | 太鼓の「ドン」 |

- 予告の残り時間は、画面の外周が赤く縮む枠で示す
- 師範の声で「伏せよ！」「受けよ！」と叫ぶ。号令は日本語のままにし、各言語の字幕を小さく添える
- S判定の瞬間は、一瞬のスロー、画面の停止（ヒットストップ）、刃鳴り、斬撃の残像で「決まった」を伝える
- 息遣いや抜刀音などの環境音を入れる。動画でも、環境音の有無で伸び方に大きな差が出た

### 武器の音

| 武器 | 通常の命中 | クリティカル（S判定） |
| --- | --- | --- |
| 刀 | 「ヒュッ」という風切り音 | 刃鳴りと、余韻の長い響き |
| 短刀 | 短く高い風切り音 | 高い金属音が2回重なる |

重い武器ほど音を低く重くし、入力した重さが耳でも分かるようにします。

### リザルトとドロップ

- EXPバーは画面幅いっぱいの太さで、金色で伸びる。満タンで光り、「LV UP」の大きな印と音
- 数字はスロットのように数え上げて止まる
- 装具は画面中央に大きく現れ、等級の色で光る。「刀袋の紐が解かれる」など、和の演出に寄せる

## 見た目とシェア

プレイ中のプレイヤーは**影絵**で描きます。シェア動画では**自分が実写、師範が灰色の影**になり、顔には鬼面を自動で重ねます。

| 場面 | 自分 | 師範 |
| --- | --- | --- |
| プレイ中 | 影絵。カメラに映る自分の骨格に、侍の影を重ねて描く | 半透明グレーの影 |
| シェア動画 | 実写。顔に鬼面を自動で重ねる | 半透明グレーの影 |

- 人が投稿したくなるのは自分の姿です。そばに師範の影があることで、「NINJA SAMURAI WORKOUT」の動画だと一目で分かる
- 鬼面は、顔を出したくない人への配慮と、ブランドの印を兼ねる。面の種類は買い切りで増える
- 影斬り（師範を追い越した瞬間）や、とどめの一撃など、「決まった」場面を自動で切り出して短い動画にする
- 書き出しは端末の中で行い、そのままInstagramのリールに渡せるようにする
- 実写を使うのは、本人がシェアを選んだときだけ。それ以外の映像は端末の外に出さない

## 妖怪の絵

妖怪のイラストは**Nano Bananaで一気に作ります**。数を稼ぐため、「基本の姿×変種」で組み立てます。

- 基本の姿を作り、それぞれに通常・金色・大将などの変種を用意する
- 画風を先に固める。今の画面の「藍色の夜と金・朱」に合わせ、浮世絵や墨絵風にそろえる
- 画風をそろえるため、共通の画風指定と、妖怪ごとの差分だけを変えるプロンプトの型を作ってから量産する
- 当たりの座敷童、各階のボス、一斉討伐の大妖怪は、他より丁寧に仕上げる
- 妖怪の由来を図鑑に短く載せる。海外の人には、日本の伝承を知る楽しみになる
- 量産はGoogle WorkspaceのGeminiやVertex AIなど、業務向けの経路で行う。商用利用にはこの経路が案内されている。Googleは生成物の所有権を主張しない。見える透かしの入った画像は使わず、透かしを消す加工もしない

権利まわりの注意は2つです。プロンプトに既存の作家名や作品名を入れないこと。似た絵になると、権利侵害の責任を負うのは使った側です。また、AIだけで作った絵は著作権で守られにくいとされるため、ボスや座敷童など看板になる妖怪には人の手で仕上げを加えます。

出典：[Gemini API 追加利用規約](https://ai.google.dev/terms)、[Nano Bananaの商用利用（Google Workspace販売代理店の解説）](https://googleworkspace.tscloud.co.jp/gemini/nano-banana-commercial-use)

## 収益

**遊びはすべて無料、「もっと楽しむため」の要素を買い切りで売ります**。プレイスタイルに合わせて、買う範囲を各自が選べる形です。

| 区分 | 中身 | 料金 |
| --- | --- | --- |
| 遊び | 妖怪退治、登頂、一斉討伐、ランキング、影レース、公開中の秘伝 | 無料 |
| 伝書 | 1つの技を深く知るための解説（画像＋文、または動画）。買うとその技の師範の影を何度でも呼び出せる | 1技100円程度の買い切り |
| 快適さ | 武器登録の3枚目、装具の保存枠など | 買い切り |
| 鬼面 | シェア動画で使える面の種類 | 買い切り |
| 心付け | 師匠に茶を出す。お礼の声や茶碗の印がもらえる | 任意。何度でも |

- 伝書は、将棋アプリの戦法解説のように「この技を極めたい」人がその技だけを買う形
- 体を動かす基本は、絶対に課金の壁の向こうに置かない
- 月額は公開時には入れない。更新が軌道に乗ったら、全伝書が開く「月謝」を後から足せる作りにしておく
- 価格は、その国で一番気軽に払える額にそろえる（日本なら100円）

### 鬼面の案

最初の1つは無料で、残りは1面100円です。それとは別に、**お金では買えない面**を用意します。全部買えてしまうと、面が腕前の証にならないからです。

| 区分 | 面 | 手に入れ方 |
| --- | --- | --- |
| 最初から | 鬼面（師範と同じ面） | 無料 |
| 侍の面 | 面頰（甲冑の顔当て）、赤鬼、青鬼 | 1面100円 |
| 忍の面 | 忍の覆面、烏天狗、狐面 | 1面100円 |
| 能と祈りの面 | 般若、天狗、小面（能面） | 1面100円 |
| 遊びの面 | ひょっとこ、おかめ | 1面100円 |
| 腕前の証 | 金の鬼面（初段）、影の面（師範の影を初めて斬った）、頂の面（登頂で一定の階に到達） | 買えない。達成でもらえる |
| 妖怪の面 | 倒したボスや座敷童の面 | 買えない。まれにドロップ |

- ひょっとこやおかめは、真剣な太刀筋との差で笑いが生まれ、シェアされやすい
- 面の形は伝統的な面をもとに独自に描き、既存のゲームや映画の面に似せない

### 心付けの案

師匠に茶を出す金額は3段階です。お礼はすべて見た目だけにし、遊びの有利不利には関わらせません。

| 段階 | 金額（日本） | お礼 |
| --- | --- | --- |
| 一服 | 100円 | 師範の声で「かたじけない」 |
| 茶と菓子 | 300円 | 声と、プロフィールに茶碗の印 |
| 茶会 | 1,000円 | 声と、金の茶碗の印 |

出した茶の総数で茶碗が格上げされていく仕組みにすると、何度も応援してくれる人に報いられます。他の国では、それぞれの国で気軽に払える額に合わせます。

## 多言語

**公開時は日本語と英語、その後7言語を足します**。選び方は、今の視聴者がいる国、ストアでの売上の大きさ、そしてそもそもアプリを届けられるかどうかの3つです。

| 段階 | 言語 | 理由 |
| --- | --- | --- |
| 公開時 | 日本語、英語 | 英語で米国とインドもおおむねカバーできる |
| 公開直後 | インドネシア語、スペイン語、ポルトガル語（ブラジル） | 視聴者がいる国と、ダウンロード数の多い国 |
| その次 | 韓国語、繁体中国語、ドイツ語、フランス語 | アプリへの支出が多い国 |
| 後で検討 | ヒンディー語、タイ語、ベトナム語、トルコ語、アラビア語 | 利用者が増えてから。アラビア語は右から左に書くため、画面の左右反転も必要 |
| 対象外 | 簡体中国語（中国本土）。ペルシャ語はブラウザ版のみ | 下の注を参照 |

- 技名、妖怪名、等級名は訳さずにローマ字で残し、各言語の訳を小さく添える（例：KESA-GIRI の下に Diagonal cut）
- 師範の号令は日本語のままにし、字幕を添える。日本語のカウントは、海外の侍好きには本物らしさそのもの
- 22時の一斉討伐などの時刻は、各自の現地時刻で表示する
- 文言は最初から「言語ファイル」に外出しする。後からやるほど手間が増える
- 翻訳はAIで下訳を作り、公開前に各言語のネイティブに一度確認してもらう
- ストアの紹介文とスクリーンショットも、対応する言語ごとに用意する

**対象外にした理由**

- 中国本土：課金のあるゲームを公開するには政府の版号（ISBN）が必要で、海外の会社は中国の運営会社と組まないと取れない。取得には1年前後かかることが多い（[AppInChina](https://appinchina.co/blog/how-to-publish-your-game-in-china/)、[ニュージーランド外務貿易省](https://www.mfat.govt.nz/cn/trade/mfat-market-reports/entering-chinas-mobile-gaming-market-a-guide-to-licensing-and-regulatory-approval)）
- イラン：米国の制裁により、AppleとGoogleはイランの利用者のストア利用を制限している（[調査メモ](https://webpages.notion.site/App-Marketplaces-b8f5361357394cf984d7d17f24afb0c5)、[Arab News](https://arabnews.com/node/2324401/)）。そのためイランには、ストアではなく無料のブラウザ版をペルシャ語付きで公開する（課金なし）。イラン国内から開けるかは、公開前に現地の知人に試してもらう
- インドはダウンロード数が世界で最も多い一方、売上の順位はずっと低い（[AppDrift](https://appdrift.co/blog/best-languages-app-localization)）。英語で届く人も多いため、ヒンディー語は後に回す

## 技術の前提

今はブラウザで動くものをiPhoneで試しています。**このコードを包んで、iPhoneとAndroidのストアに出す**のが第一候補です。判定の精度はコード側で詰めます。

- 骨格の推定と判定はすべて端末の中で行う。「部屋の映像はどこにも送られない」と言える
- サーバーで持つのは、アカウント、ランキング、影（骨格データ）、秘伝と伝書の配信、登頂のその日の山の設定
- アカウントはAppleとGoogleのログインで作れるようにし、登録の手間を減らす
- iPhoneのヘルスケア、Androidのヘルスコネクトに運動時間と消費カロリーを記録する
- ただWebサイトを包んだだけのアプリは、Appleの審査で落とされることがある。ヘルスケア連携、シェア、振動など、スマホならではの機能を入れる
- スマホは縦置きに固定する（シェア動画にも縦が合う）。何m離れれば全身が映るかは実機で試して決める。決まったら、初回起動時に「ここに立って」と枠を合わせる手順を入れる
- PCよりスマホの方が骨格推定が重くなりやすい。動きの滑らかさを、iPhoneとAndroidの実機それぞれで確かめる
