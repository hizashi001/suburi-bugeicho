## 1. このゲームの位置づけ

- 本体はカメラで素振りを判定するアプリ「NINJA SAMURAI WORKOUT: GHOST」。旅の影は、そのサブゲームの「旅」にあたる。
- 主人（プレイヤー）が筋トレをしない時間に、自分の影が旅に出て、妖怪を斬りながら距離を進む。
- 目標は、リアルな動きよりも**「思わず触ってしまう・何度も起動してしまう」ゲーム性**。
- 見た目の参考は First Cut: Samurai Duel。人気ドット絵ソシャゲ並みの、商品化できる品質を目指す。

## 2. 決定済みの仕様

### 戦闘
- **一撃必殺はNG。** 妖怪はタフにする。影が主人より簡単に倒すと、影の方が強いことになってしまうため。
- 開いている間は、連続タップで攻撃コンボが続き、早く倒せる。覚えたスキルも使える。
- **スキルは4枠。** 覚えた技から構えを問わず選ぶ。駆け抜け一閃のような決め技も、この選択式にする。
- 技はスキル経験値で育つ。極になると倍率が上がり、たまに2回発動する（極連撃）。
- **★必ず引き継ぐ：技が「極」に達したら、タップコンボを自動化する。** データを組む側で実装する。
- 強敵や倒せない敵に出会ったら、「本人が斬るモード」に移れるようにする予定。別で開発中の、カメラでスマホを振る動きを読み込むモードで、試作にはまだ入っていない。

### 進行
- **進行を止める関所はNG。** 勝てば進み、負ければ数里前の鳥居から再開する（ゾンビアタック）。ここで筋トレが必要になる。
- 一定の里ごとにボスの関を置くのはOK。関の中では距離が進まず、雑魚も出ない。
- 通常は画面に妖怪1体ほど。手間取ると、右から次々に湧いて増えていく（タワーディフェンス風）。
- 走り寄って斬るのはボス（と大将・座敷童）だけ。

### 妖怪の階級
- 通常・金・大将・ボス・座敷童の5つ。
- 座敷童はまれに出て、レアアイテムやレア効果付きアイテムのドロップ率を上げる。

### 出来事
- **百鬼夜行：** ランダムに起こる。ぬらりひょんが率いる、打たれ弱い雑魚の大群。死に戻ると消える。数が多いボーナスチャンス。
- **逢魔が時：** 現実の日没前後1時間に連動する。妖怪が強くなり、湧きも増える。

### 演出
- 斬った妖怪は、血ではなく**墨と霊気**で消える。
- 留守中の旅日記と、妖怪図鑑（時間帯限定の妖怪あり）は採用。
- 技名は大きな筆文字で出す。墨が散り、『大神』のような雰囲気で、1文字ずつドン、ドン、と叩きつける。実装済み。

## 3. 素材の作り方

| 対象 | 作り方 |
|---|---|
| 影（主人公） | Gemini（Nano Banana）で決めポーズを作る → ClaudeがPixelLab用に位置をそろえる → PixelLabで最初と最後のコマの間を補間（4〜12コマ） → Claudeがアトラスにまとめる |
| 妖怪 | ヒデキの墨絵イラストを、Nano Bananaで250×250のドット絵にする → PixelLabで動きのGIFにする |
| エフェクト | PixelLabのVFXで作り、透過GIFで書き出す |

- **妖怪の元イラストは残しておく。** 図鑑・カットイン・リザルト画面で使う。
- **PixelLabの設定：**
  - フレームカウントは偶数で4〜12。最初のコマは数に入らない。
  - 背景は「なし」。
  - ループさせる場合は、最初と最後のコマに同じ画像を入れる。
- **背景色の注意：** マゼンタの背景は出力を汚した。白か灰色の方がよい。透過の開始画像はClaudeが用意する。
- ネットの許可リストの都合で、PixelLabやLitMediaのAPIにはこの作業環境から接続できない。
- **一反木綿のように、長い布や髪が体の外へ流れる妖怪はGIFに向かない。** コードで帯ごとに波打たせる方式（`drawRipple`）で動かしている。

## 4. コードの構成

zipの中身：

| フォルダ | 中身 |
|---|---|
| `code/` | ページのソースをブロックに分けたもの。ここを編集する |
| `build/` | 組み立て・アトラス作成のスクリプト |
| `page/` | 公開する一式 |
| `art/` | 元素材 |

`art/` の内訳：
- `hero_clips`：影の動き c01〜c12、各5コマのPNG
- `hero_moves2`：動き d00〜d16 のGIF
- `hero_walk_run_old`：歩き・走り・旧攻撃
- `yokai`：妖怪
- `fx`：エフェクト16種
- `kage_chudan_250.png`：中段の構え

**ページの組み立て**（`build/assemble.py`）
- `shell_head6.html` のあとに、次のブロックを順に連結する：
  `moves11.js` → `canvas_sound7.js` → `drawframe3.js` → `drawslash.js` → `drawarc3.js` → `samples.js` → `fx3.js` → `ink3.js` → `game12.js` → `skills4.js` → `ui4.js`
- 先頭は `shell_head9.html`。`__VFXATLAS__`（vfx.json）と `__ITEMS__`（items.json）も差し込む。
- 先頭は `shell_head8.html`。旧版（moves6/7, canvas_sound5/6, game7/8, shell_head6/7）は残してあるが使わない。
- `ui4.js` の最後でゲームを起動する（ループもここ）。
- 文中の `__ATLAS__` / `__YATLAS__` / `__FXATLAS__` を、`heroM.json` / `yokai.json` / `fx.json` の中身に置き換えて、`page/index.html` を作る。

**アトラスの作り直し**
- **影：** `hero_build.py` で `hero.png` と `hero.json` を作る（全体を×0.79に縮小、色数を保ったまま）。続けて `hero_mouth.py` で口の位置を足し、`heroM.json` を作る。
  - ただし `hero_build.py` が読む中間ファイル（clips.npy 等）はzipに無い。**新しい影の動きは `hero_add.py` で既存アトラスに書き足す**（`ADD` に キー と GIF を足して実行。GIFの1コマ目は開始画像なので捨て、2コマ目以降を使う。口の位置も自動で付く）。
- **妖怪：** `ybuild2.py` で作る（`ybuild.py` は旧版。2はパスを相対にし、ループGIFの最後の重複コマを自動で捨てる）。
  - `SPEC` に、妖怪ごとのファイルと目標の高さを書く。
  - 足元の下に出る地面の線は自動で消す。
  - 一つ目小僧・提灯お化け・一反木綿は5コマのGIF。
- **エフェクト：** `fxbuild.py` で作る。
- **背景：** `bgbuild.py` で作る。元画像は4px四方で1ドット（2576×1093 → 644×273）。各ドットの中央で1pxに戻し、下の黒い帯を切り落とし、中景はほぼ黒を透明にする。ゲームでは等倍のまま、画像の下端を地平線に合わせ、上の空は遠景のいちばん上の色で塗り足す。
- `hero_build.py` / `fxbuild.py` 内のパスは前の作業環境のもの（`/home/claude/ghost/...`）なので、使う前に直すこと。`hero_add.py` / `ybuild2.py` / `bgbuild.py` / `assemble.py` はどこでも動く。

### 主なしくみ（`game7.js`）

**画面と位置**
- `G.x` が影の道のり上の位置、`G.cam` が画面の位置。
- 画面上の位置は `SX(wx)` で求める。`HXS` は影の画面上のx。

**技のつながり**（`moves6.js`）
- 技は「構え（ハブ）」から「構え」へつなぐ形で組んでいる。ハブは次の15種：
  中・上・昇・振・袈・脇・屈・空・竜・傷・立・居・血・礼・倒
- 各技は、構えごとの重み付きリスト `ATTACKS` から選ぶ。戻りの動きは `RETURNS`、タップなしでも続く構えは `FLOW`。
- 各技に、当たるコマ・浮き・範囲・相手の反応・着地の衝撃・鍔鳴りのコマを持たせている。
- タップすると、当たった後や戻りの途中で次の技に切り替わる（キャンセル）。

**戦闘の手触り**
- 斬るたびに妖怪が押し戻され、影も一歩進む。
- 間合いの外に妖怪がいると、影が踏み込む（速さ `STEP_V`）。
- 前にいる妖怪は最大3体まで攻撃してくる。
- 空を飛ぶ妖怪は頭上に浮き、攻撃の前に急降下する。対空の技が自動で選ばれる。
- 大将とボスは、体力が0になると動きが止まる。影が納刀して鍔が鳴った瞬間に崩れ落ちる。

**駆け抜け一閃**
- 気（`KI_MAX` 24回分の命中）が満ちると自動で発動する。
- 画面が白く光り、筆文字の技名が出る。影は敵の向こう側へ抜け、納刀の鍔鳴りで、斬った妖怪に順に雷が走って倒れる。

**その他**
- ボスの関は `GATE` = 3000pxごと。
- 倒れたときの出直しは `SETBACK` 1800px。そのあと3秒間は結界で攻撃を受けない。
- 真っ二つの演出：死体を一度画像に写し、体の真ん中を斜めに切る。上半分が滑り、点滅して墨と霊気が弾ける。
- 筆文字の技名：`showBanner(text, freeze)`。フォントはGoogle Fontsの Yuji Syuku。
- **呼吸：** 影が中段に戻るたびと、待っている間0.9秒ごとに `breathe()` を呼ぶ。口から白い息が流れ、青白い霊気が立ちのぼる。次の技までの待ちは `AUTO_WAIT` 0.4秒。
- 日没の時刻：NOAAの近似式で計算。経度は標準時から推定し、緯度は35.7に固定。

**主な数値**（すべて仮）

### 脳汁演出フェーズ2（Geminiの案をもとに、既存のしくみに合わせて実装）
| 項目 | 中身 | 場所 |
|---|---|---|

| ヒットストップ＋スロー | 既存の `G.stop`（完全停止）のあとに `slowmo(秒, 倍率)` が続き、終わると一気に等倍へ戻る。スローの時計は実時間 | game8.js `loop()` |
| 手応えのまとめ | `feel('crit' / 'rare' / 'kill' / 'finish')` が停止・スロー・揺れ・振動を一度に出す。**本人が斬るモードのS判定は `feel('crit')` を呼べばよい** | game8.js |

## 14. これまでのヒデキのフィードバック（すべて対応済み）

- 敵に当たると足が止まって停滞して見える → 押し戻し・前進・踏み込み・駆け抜け一閃で解決。
- 敵が重ならず1列に並ぶ → 群れになって重なるようにした。
- 雑魚の出現頻度を下げる。

- 敵が小さくて刀が当たっていないように見える → 敵を大きくした。

- 空を飛ぶ敵は頭より上を飛び、対空の技を自動で出す。
